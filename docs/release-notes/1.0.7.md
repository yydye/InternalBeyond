# InternalBeyond 1.0.7

本版整理了整体视觉层次，让界面更接近原版桌面版的质感。

- 非 Home 页面的背景氛围回到统一的雾面基调，各页面之间不再忽明忽暗
- 卡片、面板与输入控件重新分出层次：可编辑的对象更像"实体"，底部控件退到它下面
- Memory 记忆卡、API 设置卡、Image Router 路由卡补上了顶部的一线冷光，暗色主题下层次更清楚
- 浅色主题（Internal）保持原样，逐项实测未发生变化
- 前端源码统一为 UTF-8 BOM + LF，避免不同编辑器造成的乱码与换行差异
- 修复新手引导「零基础使用指南」里的示意图在正式安装版中打不开的问题
- 恢复「朋友圈 / 动态」在桌面版的入口：此前它在顶部导航里被隐藏，桌面上无路可进
- 修正 API 页 Middle Brain / Image Router 过于透明的问题：这两块此前直接浮在模糊底图上（实测为全项目最平的一组），现已接回对象卡材质
- 顶部导航右上角新增「More」菜单：把收藏夹、Role DM、日记、主动消息、Apps、经济、打包中心、系统诊断这八个此前在桌面版没有入口的页面收进一个下拉，App Store 现在可以进去了

未改动：页面结构、导航、Home 页面、既有数据与 P38 集成。
