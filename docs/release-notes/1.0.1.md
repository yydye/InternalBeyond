InternalBeyond 1.0.1 —— 第一个可以自己更新自己的版本

这一版新增了「应用内更新」：以后有新版本时，打开应用的「诊断」页面就能看到一张更新卡片，点一次「下载并安装」，程序会自己下载、校验、关闭旧版本并替换为新版本，然后自动重新打开。

请注意：从 InternalBeyond 1.0.0 升级需要手动安装一次 1.0.1。请到发布页面下载 InternalBeyond-Setup-1.0.1.exe 并运行（覆盖安装即可，你的数据不会丢失）。从此版本开始，后续版本可直接在应用内检查、下载并安装更新。

本次更新内容

- 诊断页面新增「更新」卡片：显示当前版本、是否有新版本、更新说明、下载进度与安装状态。
- 一键下载并安装新版本；安装完成后自动重新打开 InternalBeyond。
- 下载的安装包会做完整性与版本校验，校验不通过就不会安装。
- 更新检查是可选且无感的：不联网、检查失败或更新出错都不会影响正常使用，也不会拖慢启动。
- 安装新版本前会先安全关闭正在运行的 InternalBeyond（只关闭它自己的实例），不影响电脑上其他软件。
- 升级不会动你的数据：角色、API 配置、Memory、Diary、朋友圈等全部保留，不需要重新配置。

如果你更习惯手动升级，也可以在发布页面下载安装包覆盖安装，效果相同。

感谢使用 InternalBeyond。
