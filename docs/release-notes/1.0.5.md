InternalBeyond 1.0.5

这是一个以一致性、稳定性与安全为主的版本，同时带来了一个新功能：角色私信。

本次更新内容

一、新增：角色私信

角色与角色之间现在可以互相发私信。这是一条只属于这两个角色的独立对话线，和你与角色之间的聊天是分开的。

- 每个角色对另一个角色都有一份自己的看法，而且是有方向的：大黑塔怎么看阮·梅，和阮·梅怎么看大黑塔，可以完全是两回事，两边不会共用同一份关系。
- 角色能看到对方的公开简介（身份、特征、兴趣），所以它们之间说话能对上号，而不是凭空猜对方是谁。公开简介只包含角色主动公开的部分，不包含任何私密设定，也不包含你的 API 配置。
- 私信是持续的：关掉应用再打开，两个角色仍然记得刚才聊到哪；更早聊过的内容会被整理成一份「共同经历」，跨会话保留下来。
- 这份共同经历对两个角色是同一份、逐字相同，它不属于任何一方，所以不会各自记成两套互相矛盾的历史。
- 它由程序确定性地整理，不会额外调用模型，也不会把私信内容写进任何一个角色的私人长期记忆里。
- 默认不会自己发起私信：只有在你要求时才会进行。

二、聊天、记忆、理解与朋友圈收敛到同一个权威

以前这些数据在桌面端和本机服务（Home Node）两处各自维护，表现就是偶尔的不一致：同一条记忆在一处更新了，另一处还是旧的。现在只有一个权威存储负责写入与读取，桌面端改为向它请求，不再自己写。这从根上消除了「同一个角色在不同入口表现不一致」这一类问题。

三、手机端支持：设备配对与局域网访问

本机服务现在支持设备注册、配对与每台设备独立的令牌，并新增了带版本的接口，手机端可以通过局域网与电脑上的本机数据对话。

- 局域网访问只会在设备认证被真正证明之后才打开。
- 修复了一个真实问题：以前仅凭「连接来自本机回环地址」就会发放设备凭据，现在不会了。
- 修复：向手机端发送时，角色人格没有随请求一起送达模型，导致模型报出别的身份；现在人格会正确送达。
- 手机端聊天修复：流式回复被显示两次、断开后无法重新配对、你的发言与回复错位。

请注意：手机端 App 本身不包含在这个安装包里（本安装包只含 Windows 桌面端）。这一节增加的是电脑端为手机提供支持的能力。

四、安全加固

- 本地 HTTP 边界新增来源校验，并且在无法判定请求来源时选择拒绝，而不是放行。
- 局域网语音与 TTS 的认证方式与桌面端对齐。

五、稳定性与性能

- 新增组件注册表与实时健康汇总，服务状态不再靠推断。
- 后台服务意外退出后会有有界的自动恢复：有重试预算和退避，超过预算就停下并如实报告，不会无限重启。
- 优雅关停：关闭应用时会先证明要停的是自己的实例，并且不会留下孤儿进程；不属于本安装目录的进程一律不动。
- 有界上下文：发给模型的上下文不再无上限增长；可选的聊天能力改为按需注入，减少每个回合的开销。
- 每个 AI 回合只有一个执行预算和一次工具循环归属，避免同一个动作被重复执行。

六、Middle Brain 完整性

- 完整性裁决的状态现在如实表达，不再被压平成一个含混的是或否。
- 在裁决尚未完成时，由模型派生的副作用会被阻断。
- 被阻断的动作会明确告诉你它没有发生，而不是静默跳过。

七、其它修复

- 群组：用户提供的自我介绍等元数据不再被当成提示词结构的一部分。
- 朋友圈：变更投递有上限，不再出现排队阻塞；镜像替换经过授权且是原子的；权威存储的生命周期已闭合。

关于升级

- 如果你正在使用 1.0.1 或更新的版本：打开应用的「诊断」页面，点一次「下载并安装」即可。程序会自己下载、校验、关闭旧版本并替换为新版本，然后自动重新打开；你的角色、API 配置、Memory、Diary、朋友圈等数据全部保留，不需要重新配置。
- 如果你还在使用 1.0.0（或更早）：请到发布页面下载 InternalBeyond-Setup-1.0.5.exe 手动安装一次（覆盖安装即可，你的数据不会丢失）。早期版本还没有应用内更新的能力，所以这一跳必须手动走一次；此后就可以一直用应用内更新了。

如果你更习惯手动升级，也可以在发布页面下载安装包覆盖安装，效果相同。

感谢使用 InternalBeyond。
