InternalBeyond 1.0.3

这是一个修复版本。

本次更新内容

- 修复了欢迎页的动态水纹特效有时整片不显示的问题：当应用带着某个页面直接打开（例如上次停在「诊断」页），而欢迎页仍在显示时，水纹会完全消失、只剩下背景图。现在无论从哪个页面进入，欢迎页的水纹都会正常显示。
- 这个缺陷从 1.0.0 起就存在，只是长期被另一个问题（欢迎页背景图不显示）掩盖着；1.0.2 修好背景之后，它才变得看得见。

关于升级

- 如果你正在使用 1.0.1 或更新的版本：打开应用的「诊断」页面，点一次「下载并安装」即可。程序会自己下载、校验、关闭旧版本并替换为新版本，然后自动重新打开；你的角色、API 配置、Memory、Diary、朋友圈等数据全部保留，不需要重新配置。
- 如果你还在使用 1.0.0（或更早）：请到发布页面下载 InternalBeyond-Setup-1.0.3.exe 手动安装一次（覆盖安装即可，你的数据不会丢失）。早期版本还没有应用内更新的能力，所以这一跳必须手动走一次；此后就可以一直用应用内更新了。

如果你更习惯手动升级，也可以在发布页面下载安装包覆盖安装，效果相同。

感谢使用 InternalBeyond。
