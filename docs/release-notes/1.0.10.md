# InternalBeyond 1.0.10

本版加入 Memory Atmosphere 与 Presence 2.0，并收录近期聊天接入、App Builder 隔离及本地服务稳定性更新。

- Memory 页面新增可关闭的氛围视觉层；它只读取现有界面状态，不写入 Memory 数据
- Presence 2.0 识别离开与归来，并可把近期离开作为自然聊天背景；静默感知与主动迎接独立设置，主动迎接默认关闭
- 主动迎接会检查重复事件、冷却、聊天输入和进行中的对话，避免刷屏或打断
- 增加可选 NapCat / OneBot 接入与账号隔离配置；安装、登录和连接均需用户确认
- App Builder 预览使用隔离沙箱；本地服务对数据库故障分类，并改进有界恢复与关闭流程
- 修复 Presence 启动上下文初始化错误，并更新相关浏览器回归断言
