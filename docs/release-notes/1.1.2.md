# InternalBeyond 1.1.2

1.1.2 is a Windows desktop release that brings the Home Node, Memory, voice, workspace and social features into one local-first application. The installer and optional DSH Runtime are separate downloads.

## Highlights

- **QQ integrations** — optional QQ Official Bot and OneBot / NapCat connections, with account separation and user-managed authorization. Configure your own compatible account and approved contacts; no account credentials are included.
- **Voice and animated characters** — Voicebox voice profiles, ASR / TTS controls and voice calls. DIY Workshop's Puppet Studio edits layered characters, bones and motions for the existing IB Puppet call renderer. Character artwork is user-provided; Cubism Core and sample characters are not bundled.
- **Memory and Home Node** — improved Memory association, recall and history views, with production Memory V1 remaining the default. Memory V2 recall remains an explicit opt-in. Home Node owns canonical chat, memory and social data on the local device.
- **Work Mode and DSH** — consented local Agent runs, project files, results and recovery controls. The Windows DSH Runtime is optional and distributed separately; the main installer does not require it.
- **More companion surfaces** — map and travel records, local music, cinema activities, Presence, Agent Economy, and continued Moments / Social Net improvements.
- **Security and reliability** — tighter credential authority, imported-content validation, local-service ownership and recovery behavior, plus clearer update and diagnostic status.

## Downloads

- **InternalBeyond-Setup-1.1.2.exe** — Windows 10+ installer. Verify it against `SHA256SUMS.txt` before installation.
- **InternalBeyond-DSH-Runtime-0.2.1-alpha.2-windows-x64.zip** — optional runtime for Work Mode / DSH only. Its `.sha256` sidecar records the ZIP digest. The signed DSH update index remains on its independent HTTPS distribution channel.
- **update-stable.json** — stable in-app update manifest. It is published after the installer and checksum assets so clients never see a manifest before its installer exists.

The repository also contains an Android Home Node client source preview; this release does not include an Android APK.

## Data and service setup

Application data stays in local browser or app storage. When you use a cloud AI provider, the request content needed for that feature—including selected conversation context or attachments—is sent to the provider configured in the app. A loopback local-model endpoint keeps that model request on-device. QQ and Voicebox integrations require the user's own service setup and credentials.
