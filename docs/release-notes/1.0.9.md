# InternalBeyond 1.0.9

本版将 QQ 官方机器人接入纳入 Windows 发行，并加入从 Dev 环境预览、确认后增量导入 QQ 设置的流程。

- QQ Official 支持 C2C 私聊与开发体验群聊，含文字、图片理解、角色选择及 `/role`、`/who`、`/reset` 指令
- 设置页提供待授权对象、角色绑定、接管状态和本地备注管理；NapCat 保留为独立的可选高级接入
- 配置迁移仅导入新增对象，不覆盖正式版已有配置；AppSecret 与 Vault 凭据不会从 Dev 复制，需在目标环境重新绑定
- 新导入的 Bot 保持断开，确认目标环境凭据和权限后再连接
- 修复短暂消息轮询失败造成的本地连接状态闪烁，并避免状态刷新重叠
- 修复 Dev 断开确认未保存导致正式版连接按钮持续阻塞的问题；正式版 Bot 状态与 Dev 手动确认分别显示
- 配置迁移预览在页面内部重绘后保留；角色映射变化会使原差异确认失效
- 修复 QQ Official 连接完成后提示仍停留在“正在连接”的问题；按当前连接操作和服务状态清理或更新提示，避免旧请求覆盖新状态
- 修复 Home Node Runner 对异常健康响应的端口归属判断，并串行化故障恢复，避免错误报告端口冲突或重复启动服务
