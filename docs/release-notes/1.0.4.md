InternalBeyond 1.0.4

这是一个功能与修复并存的版本。

本次更新内容

一、新增：思考深度

在「设置 → API」页的 Middle Brain 区块里，新增了一项「思考深度」，共五档：自动 / 低 / 中 / 高 / 最大。

- 默认是「自动」，也就是和以前完全一样：程序不会额外发送任何思考相关参数，模型保持它自己的原生行为。升级后如果你不动这一项，聊天的一切表现都不会有任何变化。
- 调高之后，受支持的模型会在回答前思考得更久、更深入（回答可能稍慢，也更容易消耗额度）；调低则更省、更快。
- 目前只有一部分模型确认支持这一项（例如 DeepSeek 的 deepseek-flash，支持「低 / 高 / 最大」三档）。没有确认支持的模型不会因此报错，只是这一项对它暂时不生效——宁可不发送，也不拿你的真实对话去做试验。
- 「思考深度」和旁边的「处理速度」是两个互不影响的开关：前者决定模型想多久，后者决定服务的延迟策略。

二、修复：Middle Brain 的开关状态不再显示成假的「已启用」

以前改动了 Middle Brain 的设置但还没有保存时，卡片上的徽标会显示成「已启用」，而实际运行的仍然是上一次保存的设置。现在这种情况会明确显示为「未保存」，只有在真正生效时才会显示「已启用」。

三、修复：Middle Brain 改用本地处理时，结果没有进入对话

当 Middle Brain 连不上你配置的服务、退回到本地压缩处理时，处理结果以前不会进入角色对话（等于开着却没有任何影响）。现在两条路径的行为一致。

四、修复：图片相关设置

- 「图片路由」里的「+ 新建」按钮已移除：它点下去打开的其实是「角色 API 编辑器」，容易让人误以为图片有独立的配置来源。现在文案改成了「图片 API 来源」，并说明图片凭据取自该来源的哪几项；需要新建来源时，请到「角色库」的 API 编辑器里新建。
- 修复了一个真实的残留问题：新建角色时，会静默继承上一个角色的图片接口地址与图片 Key。现在新建角色会把这些图片相关字段一并清空。
- 修复了 API 页卡片之间的间距：「系统诊断」入口与 Middle Brain 之间此前贴在一起，现在与其它卡片保持一致。

关于升级

- 如果你正在使用 1.0.1 或更新的版本：打开应用的「诊断」页面，点一次「下载并安装」即可。程序会自己下载、校验、关闭旧版本并替换为新版本，然后自动重新打开；你的角色、API 配置、Memory、Diary、朋友圈等数据全部保留，不需要重新配置。
- 如果你还在使用 1.0.0（或更早）：请到发布页面下载 InternalBeyond-Setup-1.0.4.exe 手动安装一次（覆盖安装即可，你的数据不会丢失）。早期版本还没有应用内更新的能力，所以这一跳必须手动走一次；此后就可以一直用应用内更新了。

如果你更习惯手动升级，也可以在发布页面下载安装包覆盖安装，效果相同。

感谢使用 InternalBeyond。
