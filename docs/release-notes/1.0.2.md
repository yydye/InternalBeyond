InternalBeyond 1.0.2

这是一个修复版本。

本次更新内容

- 修复了安装版第一次打开时，欢迎页画窗的背景没有显示、只剩一层空雾玻璃的问题。安装包现在会带上这张背景图，安装完成后第一次打开就能看到正常的画窗背景。

关于升级

- 如果你正在使用 1.0.1 或更新的版本：打开应用的「诊断」页面，点一次「下载并安装」即可。程序会自己下载、校验、关闭旧版本并替换为新版本，然后自动重新打开；你的角色、API 配置、Memory、Diary、朋友圈等数据全部保留，不需要重新配置。
- 如果你还在使用 1.0.0（或更早）：请到发布页面下载 InternalBeyond-Setup-1.0.2.exe 手动安装一次（覆盖安装即可，你的数据不会丢失）。早期版本还没有应用内更新的能力，所以这一跳必须手动走一次；此后就可以一直用应用内更新了。

如果你更习惯手动升级，也可以在发布页面下载安装包覆盖安装，效果相同。

感谢使用 InternalBeyond。
