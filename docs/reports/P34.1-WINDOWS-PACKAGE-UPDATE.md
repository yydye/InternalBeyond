## 7. 诚实限制：live Astra 未执行

- 安装版 Middle Brain 默认 **未启用**（`apiSettings['middle_brain'].enabled=false`），Direct Channel 需要用户先配置/绑定才可调用。
- 真实 Astra 调用需要用户的真实 provider 凭据与授权环境；沿用此前 P32/P34 的纪律，**本轮未发起真实 provider 请求**，因此不声称 “live Astra 200”。
- 已验证的是**完整调用链**：`Direct Channel → middleBrainDirectModelCall → middleBrainModelCall → resolveRuntimeCredential(credentialRef) → AstraAdapter → _ibApiPost`，其中凭据解析、就绪判定、fail-safe、无明文落盘均在安装后 payload 上通过。
- 说明：以 `file://` 打开安装版面读取到 `host=browser / resolverAvailable=false`，这是因为 Tauri 源（`tauri.localhost`）与 `file://` 源不同；安装版真实运行于 Tauri，`credentialResolver` 可用（`host-capability.js` 的 `tauriCredentialResolver`）。
