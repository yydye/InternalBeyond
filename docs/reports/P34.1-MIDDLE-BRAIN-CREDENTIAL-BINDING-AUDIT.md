## 1. 只读审计结论（四个问题）

### 1.1 `middleBrainDirectModelCall` 使用哪个 apiConfig？

**不使用 `apiConfigs` 记录。** 它使用 Middle Brain 自己的单例配置 `apiSettings['middle_brain']`：

```text
IB.middleBrainDirectModelCall  (assets/js/middle-brain.js:261-266, consumer='middle_brain.direct', jsonMode=false)
  → ASTRA.middleBrainModelCall  (assets/js/middle-brain-astra.js:127)
  → CFG.getMiddleBrainConfig()  (assets/js/middle-brain-config.js:92-106 → dbGet('apiSettings','middle_brain'))
  → buildMiddleBrainResponsesRequest (assets/js/middle-brain-astra.js:69)
  → IBModelCore.AstraAdapter.buildResponsesRequest (assets/js/ib-model-core.js)
  → root._ibApiPost / fetch (assets/js/communication.js:147)
```

### 1.2 Astra adapter 使用哪个 provider？

- `provider`：默认 `'astra'`（`MB_DEFAULTS.provider`，`assets/js/middle-brain-config-core.js:32`）
- `endpoint`：默认 `https://api.openai.com/v1/responses`（`:33`）
- `model`：默认 `gpt-6-astra`（`:34`）
- wire 归一：`IBModelCore.AstraAdapter`（Responses API），失败时回落 Chat Completions（`middle-brain-astra.js:82-92`）

### 1.3 credential resolver 是否接入？

**未接入到模型调用。** 只有**只读状态包装** `getMiddleBrainCredentialStatus()`（`assets/js/middle-brain-config.js:140-183`）读取 `cfg.credentialRef` 并经 `IB.credentialAuthorityConsumers.queryBinding` 查询状态；传输层从不调用 `IB.host.credentialResolver.resolve()`。

对照普通 Chat 的正确路径（`assets/js/communication.js:248-279` `_ibWithRuntimeApiCredential`）：从 `cfg` 剥掉 apiKey → `IB.host.credentialResolver.resolve(cfg.id)` → 运行时注入 → 请求后清零。Middle Brain 未走这条路径。

### 1.4 是否仍依赖旧 apiKey 字段？

**是，两处**：

| 位置 | 依赖 |
| --- | --- |
| `assets/js/middle-brain-config-core.js:151-153` `middleBrainApiReady(c)` | 就绪判定要求 `String(c.apiKey||'').trim()` 非空 |
| `assets/js/middle-brain-astra.js:146,150,255,259` | `Authorization: 'Bearer ' + cfg.apiKey` |
| `assets/js/middle-brain-judge.js:127-129` | 同上（Judge 独立构造请求头） |

即：Middle Brain 需要把**明文 apiKey 持久化在 `apiSettings['middle_brain']`（IndexedDB）** 才能调用 —— 与目标约束（secret 不进 IndexedDB）冲突。

## 3. 约束核对

| 要求 | 满足方式 | 证据 |
| --- | --- | --- |
| 不修改 Vault architecture | 只**调用** `IB.host.credentialResolver` / `credentialAuthorityConsumers`，未改 resolver、binding 表或 Vault 文件 | diff 仅触及 middle-brain-* |
