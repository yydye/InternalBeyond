## 2. 架构改动（ADR Decision 1）

新增 `services/home-node/credential-access.js`：
- 复用 `active/credential-resolver.js`（Node 模块，与 Tauri `credential_resolve` 同源）；
- **allowlist**：仅允许本 Node 已发布 characters（`isAllowed(id)`）；
- **请求作用域**：`resolve(ref)` 返回 `{ok, provider, secret}`，不缓存、不落库、不日志；
- 失败返回 `{ok:false, reason}`（fail-closed）。
