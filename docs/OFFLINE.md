# InternalBeyond · 离线能力（Offline / Degradation）

> 本文区分两个常被混为一谈的概念：
> **「有本地模式」**（提供本机模型选项）≠ **「真正具备离线降级能力」**（系统在断网/缺模型时仍按预期工作）。
> 关联：[ARCHITECTURE.md](../ARCHITECTURE.md) · [AUTONOMY.md](AUTONOMY.md)（offline 降级表）· [README.md](../README.md)（本地优先中心）。

---

## 0. 一句话结论

- **基础功能**（房间/换装/主题/音乐/日志/日历显示/记忆浏览）**完全离线**——数据在 IndexedDB，无需后端。
- **AI 交互**离线的前提是**你显式配置了一个本机模型**（Ollama / LM Studio / vLLM）。**没有自动的"云→本机"故障切换**。
- **Bridge/Active/配套服务**在断网时**fail-open 降级**（Bridge 功能失败 → 各种本地回退），但**主聊天不走 Bridge**，所以主聊天依赖"模型是否能连上"。

> **Model 层是"手动离线"，Feature 层是"自动降级"。** 这是 IB 离线的真实边界。

---

## 1. 三层离线模型

```text
Cloud Model
   ↓ 不可用
Local Model（Ollama / LM Studio / vLLM，回环端点，可无 Key）
   ↓ 也未配置/不可用
Browser 兜底 / 已缓存能力
   ↓
系统仍可用（基础功能不依赖模型）
```

## 2. 哪些能降级、哪些能（要摸清）

| 能力 | 离线？ | 说明 |
|---|---|---|
| Room / 换装 / 主题 / 音乐播放 / 日志 / 日历（显示） | ✅ | 纯前端 + IndexedDB；音乐本地文件可播 |
| **主聊天（AI）** | ⚠️ 需模型 | 浏览器直连 API；云模型需联网；本机模型（回环预设）离线可用，但**是另一个独立 API 配置** |
| 本机模型预设 | ✅ 本地 | Ollama `11434` / LM Studio `1234` / vLLM `8000`，仅回环、可无 Key；需先启动对应服务 |
| 文件解析库 | ✅ 离线（已缓存） | 首次联网下 CDN 缓存；此后离线可用 |
| Python / Pyodide 运行时 | ⚠️ 需本地副本 | 只有自行提供本地副本后才算完整离线（文件解析/脚本沙箱） |
| 加密备份 / 导出 / 健康检查 | ✅ 本地 | AES-256-GCM，仅本机 |
| **Bridge 表情包** | ⚠️ fail-open | Bridge 未启动 → 弹窗提示"无法加载表情" |
| **Bridge 点歌** | ⚠️ fail-open | 失败 → 直接打开酷狗/网易云网页兜底 |
| **Bridge TTS（语音气泡）** | ⚠️ fail-open | Bridge 未配置/失败 → 浏览器 `speechSynthesis` 朗读 |
| **Bridge 推送（Bark/ntfy）** | ❌ 需联网 | 推送本身需外网服务 |
| **Active 关页调度** | ⚠️ 需模型 | 本地 companion 执行，但到点仍要调模型（本机或云端） |
| **DeepSeek 本地视觉** | ✅ 本地 | Qwen2.5-VL via Ollama（`127.0.0.1:8765`）；非原生视觉模型兜底 |
| **网络搜索** | ❌ 需联网 | 厂商搜索服务 |
| **图像生成** | ⚠️ 需模型 | 生图端点（云或本机兼容） |
| **Voice 通话（ASR/TTS）** | ⚠️ 需 Bridge+网络 | ASR 在 Bridge/服务端配置；失败降级打字/浏览器 TTS |
| **数据持久化** | ✅ 离线 | IndexedDB + 本地 JSON（companion） |

## 3. 关键区别：自动降级 vs 手动离线

- **Feature 层自动降级**：Bridge 相关（表情/点歌/TTS/上下文进度条等）**fail-open**——Bridge 挂了不影响主功能，各自有兜底（见上表" fail-open"行）。主聊天**根本不经 Bridge**，所以断网只影响"模型是否可达"，不影响页面其余功能。
- **Model 层是手动离线**：本地模型是**另一个 API 配置**，需要你**主动添加**（本地优先中心预设）。IB **没有**"云端模型连不上时自动切本地模型"的故障切换——只有**你的角色配置里**用的是本地模型，它才离线可用。

> 所以严格说：IB 的"本地优先"是**提供本机模型选项 + 把数据留在本地 + 配套能力 fail-open**；但**模型级自动降级并不存在**。要让 IB 真正离线跑 AI，需显式配置本机模型。

---

## 4. 实测建议 / 已知限制

- **主聊天完全离线**的前提：所有角色 API 配置指向本机模型（回环端点），且本机服务（Ollama 等）已启动。
- **启停顺序**：先启动本机模型服务 → 本地优先中心"探测服务" → 保存为 API 配置。
- **离线就绪度**：本地优先中心会显示文件解析库缓存、界面资源、Python 运行时的就绪度——这是**诊断**，不是自动下载。
- **未知限制**：页面后台动效/音频可视化在后台会暂停（性能）；离线时"网络搜索/图像生成/推送"不可用属**预期**，不是 bug。
